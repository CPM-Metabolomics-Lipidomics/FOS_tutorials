Background

A gene encoding MYB transcription factor, with unknown function, PttMYB76, was selected from a library of poplar trees for metabolomic characterization of the growth process in Poplar trees.

The Biological Question

The PttMYB76 gene is believed to affect different pathways in the phenyl propanoid synthetic pathway. This pathway leads to the formation of: - S- and G-lignin - Flavonoids
- Sinapate esters

Experimental Design

Poplar Plant Sampling Design

Figure: Poplar plant response vector (internodes). The growth- or time-related response vector, where internode 1 is at the top (youngest) and internode 8 at the bottom (oldest).

Sample Collection: - 12-week-old poplar plants - Two genotypes: - Wild Type (WT): Trees D, E, F (Class 0) - MYB76 modified: Trees A, B, C (Class 1) - 3 trees per genotype - 8 internodes per tree (apex removed before sampling) - Total: 46 plant samples + analytical replicates = 57 observations

Data Structure

  • N = 57 observations: 6 trees × 8 internodes + replicates
  • K = 655 variables: ¹H-NMR chemical shift regions (0.02 ppm buckets)
  • Response variable: Class (0 = Wild Type, 1 = MYB76)
  • Growth vector: Internode number (1 = top/young, 8 = bottom/old)

Understanding Scaling Methods

Before we start, let’s understand different scaling approaches:

## SCALING METHODS IN METABOLOMICS:
## 1. NO SCALING (Mean-centered only):
##    - Variables keep their original variance
##    - High-intensity signals dominate the model
##    - Use when: All variables have similar ranges
## 2. UNIT VARIANCE (UV) SCALING:
##    - Divide by standard deviation
##    - All variables have equal importance
##    - Use when: You want to emphasize small peaks equally
##    - Analysis based on correlations, not covariances
## 3. PARETO SCALING:
##    - Divide by square root of standard deviation
##    - Intermediate between No scaling and UV
##    - Large variances reduced more than small ones
##    - Preferred for metabolomics: balances signal importance

# Take a few example variables to demonstrate scaling
example_vars <- metabolomics_data[, c("NMR_1.00", "NMR_5.00", "NMR_10.00")]

# Function to apply different scaling
apply_scaling <- function(x, method = "none") {
  x_centered <- scale(x, center = TRUE, scale = FALSE)
  
  if(method == "uv") {
    return(scale(x, center = TRUE, scale = TRUE))
  } else if(method == "pareto") {
    sds <- apply(x, 2, sd)
    return(scale(x, center = TRUE, scale = FALSE) / sqrt(sds))
  } else {
    return(x_centered)
  }
}

# Compare standard deviations

Variable Importance in PLS-DA

Identifying the most important variables (potential biomarkers):

# Calculate VIP (Variable Importance in Projection) scores
# VIP > 1 indicates important variables

# Function to calculate VIP
vip_scores <- function(model) {
  # Get loadings and explained variance
  W <- model$loading.weights
  Q <- model$Yloadings
  
  # Calculate VIP for each variable
  SS <- colSums(Q^2) * colSums(model$scores^2)
  Wnorm2 <- colSums(W^2)
  SSW <- sweep(W^2, 2, SS, "*")
  
  vip <- sqrt(nrow(SSW) * apply(SSW, 1, sum) / sum(SS))
  return(vip)
}

vip <- vip_scores(plsda_model)

# Get top 30 VIP scores
top_vip_idx <- order(vip, decreasing = TRUE)[1:30]
top_vip_df <- data.frame(
  Variable = names(vip)[top_vip_idx],

Model Diagnostics and Validation

Permutation Testing

# Perform permutation test to assess model significance
set.seed(123)
n_perms <- 100

# Original Q2
original_Q2 <- Q2[optimal_ncomp]

# Permutation Q2 values
perm_Q2 <- numeric(n_perms)

for(i in 1:n_perms) {
  # Permute class labels
  Y_perm <- sample(Y)
  
  # Fit model
  perm_model <- plsr(Y_perm ~ X_pareto, ncomp = optimal_ncomp, validation = "LOO")
  
  # Calculate Q2
  PRESS_perm <- perm_model$validation$PRESS[optimal_ncomp + 1]
  TSS_perm <- sum((Y_perm - mean(Y_perm))^2)
  perm_Q2[i] <- 1 - PRESS_perm / TSS_perm
}

# Plot permutation distribution
hist(perm_Q2, breaks = 20, col = "lightblue", 
     main = "Permutation Test - Q2 Distribution",
     xlab = "Q2 Value", xlim = c(min(perm_Q2, original_Q2), max(perm_Q2, original_Q2)))
abline(v = original_Q2, col = "red", lwd = 2, lty = 2)
legend("topright", legend = c("Original Q2"), col = "red", lty = 2, lwd = 2)

# P-value
p_value <- sum(perm_Q2 >= original_Q2) / n_perms
cat(sprintf("\nOriginal Q2: %.3f\n", original_Q2))
cat(sprintf("P-value: %.3f\n", p_value))
cat(sprintf("Interpretation: %s\n", 
            ifelse(p_value < 0.05, "Model is significant!", "Model may not be significant.")))

Biomarker Validation Approach

## BIOMARKER VALIDATION STEPS:
## 1. STATISTICAL VALIDATION:
##    - VIP score > 1 (from PLS-DA)
##    - Significant univariate test (t-test or Mann-Whitney)
##    - Cross-validation confirms importance
##    - Permutation testing supports model
## 2. BIOLOGICAL VALIDATION:
##    - Link to known metabolic pathways
##    - Consistent with gene function (PttMYB76)
##    - Literature support
##    - Replication in independent samples
## 3. ANALYTICAL VALIDATION:
##    - Confirm metabolite identity (2D-NMR, MS)
##    - Quantify with standards
##    - Check reproducibility
##    - Verify not due to technical artifacts

PLS-DA (Partial Least Squares Discriminant Analysis)

PLS-DA is a supervised method that finds components maximizing the covariance between X (NMR data) and Y (class labels):

# Prepare data for PLS-DA
X <- as.matrix(metabolomics_data[, nmr_vars])
Y <- as.numeric(metabolomics_data$Class) - 1  # Convert to 0/1

# Apply Pareto scaling
X_centered <- scale(X, center = TRUE, scale = FALSE)
sds <- apply(X, 2, sd)
X_pareto <- X_centered / sqrt(sds)

# Fit PLS-DA model using plsr from pls package
# Start with 5 components, will optimize later
plsda_model <- plsr(Y ~ X_pareto, ncomp = 5, validation = "LOO")

# Summary
summary(plsda_model)

# Calculate R2 and Q2 equivalents
R2 <- R2(plsda_model)
RMSEP_values <- RMSEP(plsda_model, estimate = "CV")

cat("\nModel Quality Metrics:\n")
print(R2)
X <- as.matrix(metabolomics_data[, nmr_vars])
Y <- as.numeric(metabolomics_data$Class) - 1
X_centered <- scale(X, center = TRUE, scale = FALSE)
sds <- apply(X, 2, sd)
X_pareto <- X_centered / sqrt(sds)
plsda_model <- plsr(Y ~ X_pareto, ncomp = 5, validation = "LOO")
summary(plsda_model)

Determine Optimal Components

# Plot validation results to determine optimal components
plot(RMSEP(plsda_model), legendpos = "topright",
     main = "RMSEP for PLS-DA Model")

# Calculate Q2 (predictive ability)
# Q2 is based on cross-validation
PRESS <- plsda_model$validation$PRESS
TSS <- sum((Y - mean(Y))^2)
Q2 <- 1 - PRESS / TSS

cat("\nQ2 values by component:\n")
print(Q2)

# Typically select components where Q2 > 0.5 and stops improving
optimal_ncomp <- which(Q2 > 0.5)[1]
if(is.na(optimal_ncomp)) optimal_ncomp <- 2

cat(sprintf("\nSuggested optimal components: %d\n", optimal_ncomp))
